Dependencies used:
- NumPy
- torch, torchvision
- matplotlib
- random
Virtual Environment:
- Adauga aici

How to run this code:
1. Open git bash and insert the instruction:
   git clone https://github.com/robertbejan/deepavance/tree/main
2. Setup the virtual environment with the neceessary dependencies:
   pip install numpy
   pip install torch
   pip install torchvision etc.
3. Open miniproject_cycleGAN.ipynb and run the cells.
